## Этап 1: КТ1

### 1. Назначение программы
Программа предназначена для анализа работы облачной инфраструктуры по последовательности телеметрических измерений. Она формирует временные ряды инфраструктурных компонентов, рассчитывает производные показатели динамики, выявляет состояния компонентов и фиксирует инциденты на основе логических правил.

### 2. Описание индивидуального варианта (Вариант 15)
* **Контролируемые компоненты:** `LOG`, `QUE`, `TLS`
* **Порядок записи во входном файле:** В — `компонент–время–значение`
* **Разделитель записей:** Точка с запятой (`;`)
* **Тип последовательности:** (4) Порядок произвольный; возможны пропуски измерений отдельных компонентов.
* **Производный показатель $Q:** Логарифмическое изменение.
* **Математическая формула показателя в формате LaTeX:**
  Q[i] = \ln(X[i]) - \ln(X[i-k])
  где период сравнения k = 3, критерий L = 2.0, параметр D = 25.
* **Правило состояния компонента (Локальная аномалия):** Если текущее значение Q[i] больше предыдущего Q[i-1] и следующего Q[i+1], то состояние — `«АНОМАЛИЯ»`, иначе — `«НОРМА»`.
* **Правило инцидента (Хотя бы одна тревога):** Инцидент возникает, если хотя бы один компонент находится в состоянии `«ТРЕВОГА»` или `«АНОМАЛИЯ»`.
* **Структура Incident:**
  ```c
  typedef struct {
      int time;
      int type;
      int count;
  } Incident;
  ```
  *Поля:* номер отсчёта, тип инцидента, число проблемных компонентов.

### 3. Таблица значений телеметрии (Тестовый набор)
Исходная тестовая строка из задания:  
`LOG;1;45.5;LOG;3;46.5;QUE;5;53.0;QUE;1;55.6;TLS;5;30.9;LOG;5;52.9;QUE;3;57.0;QUE;2;53.6;TLS;3;32.4;TLS;1;33.9;LOG;4;47.0;TLS;4;31.6;LOG;2;46.0`


| Время (i)| LOG  | QUE       | TLS       |
| -------- | ---- | --------- | --------- |
| **1**    | 45.5 | 55.6      | 33.9      |
| **2**    | 46.0 | 53.6      | *пропуск* |
| **3**    | 46.5 | 57.0      | 32.4      |
| **4**    | 47.0 | *пропуск* | 31.6      |
| **5**    | 52.9 | 53.0      | 30.9      |

### 4. Ручной расчёт производного показателя Q
Так как шаг сравнения k = 3, расчёт показателя Q[i] возможен только для моментов времени i = 4 и i = 5:

* **Компонент LOG:**
  * Q[4] = \ln(47.0) - \ln(45.5) = \ln(47.0 / 45.5) \ 0.0324
  * Q[5] = \ln(52.9) - \ln(46.0) = \ln(52.9 / 46.0) \ 0.1398
* **Компонент QUE:**
  * Q[4] — рассчитать нельзя (нет данных).
  * Q[5] = \ln(53.0) - \ln(53.6) = \ln(53.0 / 53.6) \ -0.0113
* **Компонент TLS:**
  * Q[4] = \ln(31.6) - \ln(33.9) = \ln(31.6 / 33.9) \ -0.0702
  * Q[5] — рассчитать нельзя (нет данных).

### 5. Анализ состояний и ожидаемый результат
Для определения состояния `«АНОМАЛИЯ»` требуется сравнить текущее значение Q[i] с его левым соседом Q[i-1] и правым соседом Q[i+1]. На тестовом наборе из 5 точек невозможно получить три последовательных значения Q ни для одного компонента. Соответственно, условия для фиксации аномалий не выполняются.

* **Состояние компонентов:** Все компоненты находятся в состоянии `«НОРМА»`.
* **Ожидаемый результат контроля:** Инцидентов на данном наборе данных не обнаружено.

**Заключение по КТ1:** Вывод разработанной тестовой программы на языке C полностью совпадает с результатами теоретического ручного расчёта. Базовый контроль формул и логики контроля успешно пройден.
